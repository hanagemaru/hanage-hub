## 現時点のゲーム内広告収益の見立て

まだゲーム内広告は実装していない。AdSenseは2026-09-19に「有用性の低いコンテンツ」で却下されており、Google H5 Games Adsを使う前提条件も満たしていない。

現在のアクセス規模をそのまま将来にも維持できると仮定した場合でも、ゲーム内広告収益はまず月数百〜数千円程度から始まる可能性が高い、という作業仮説を置く。これは実績ではなく、一般的なゲーム広告eCPMと現在の訪問規模から置いた粗いレンジ。

重要な点:

- 現在のX広告費4,000円をゲーム内広告ですぐ回収する前提にはしない。
- 有料流入が止まればアクセスも落ちる可能性があり、収益試算もそのまま維持されない。
- 収益化の意味が大きくなるのは、検索、SNS拡散、再訪などの無料流入が増えてから。
- 広告を入れる場合も、プレイ中ではなく自然な区切りだけにする。確定ルールは `ADVERTISING_POLICY.md` に記録する。

### 広告収入モデル：必ず実測と切り分ける

**現状の実広告収入は0円**。サイトは2026-09-19にAdSense審査で「有用性の低いコンテンツ」を理由に却下され、ゲーム内広告も未実装。H5 Games Adsを含め、収益化機能の承認や導入が前提条件となる。

将来の見積もりは、実RPM不明のため **月間Visits ×（1,000 Visitsあたり仮定収益50〜500円）÷1,000** という感度分析で行う。中間シナリオは200円/1,000 Visits。これはWebブラウザゲームの保証単価・実測値・収益予測ではない。例えば「1訪問あたり広告表示1回 × 実効eCPM200円」なら200円/1,000 Visitsとなるが、実際は表示チャンス、離脱、配信充足率、国、広告形式で大きく変わる。Puttの広告配置方針は操作を邪魔しない自然な区切りであり、毎訪問で広告が必ず1回表示されるとは限らない。

| 仮定の月間Visits | 低：50円/1,000 Visits | 中：200円/1,000 Visits | 高：500円/1,000 Visits |
| --- | ---: | ---: | ---: |
| 1,000 | 50円/月 | 200円/月 | 500円/月 |
| 3,000 | 150円/月 | 600円/月 | 1,500円/月 |
| 10,000 | 500円/月 | 2,000円/月 | 5,000円/月 |
| 30,000 | 1,500円/月 | 6,000円/月 | 15,000円/月 |
| 100,000 | 5,000円/月 | 20,000円/月 | 50,000円/月 |

- **現実的な目標の順序**: 広告承認・導入後、まず月数百〜数千円の実測を作る。その後、広告によらない流入・継続が伸びれば月1万円台の達成を検討する。月数万円以上には月間数万〜十数万Visitsの持続が必要な可能性が高い。**時期・成長率はデータ不足で予測不能**。
- 中シナリオでは月1万円に**月5万Visits**、月3万円に**月15万Visits**が必要。訪問増加だけでなく、再訪とプレイ深度に応じた実効収益/Visitの確認が必要。
- 参考の集客コスト約6.70円/t.co-Visitに対し、この仮定では1訪問の広告収益が **0.05〜0.50円**。**有料広告で集めて、その一度の訪問に広告を表示して回収するモデルは成立しにくい**。X広告は作品の認知、ユーザー獲得、共有・再訪の起点と位置付け、無償流入や継続の効果込みで判断する。
- **重要**: 9/27〜29に計測された約700 Visitsを30日へ単純外挿しない。広告停止後の平常値、実広告表示回数、実RPMが未確認だから、現時点で「月○円は達成確実」とは言えない。
- 根拠となる公式指標・実装条件: [Google AdSense RPM](https://support.google.com/adsense/answer/190515?hl=ja-GB)、[ページRPM](https://support.google.com/adsense/answer/112030?hl=en-GB)、[広告RPM](https://support.google.com/adsense/answer/112032?hl=ja-GB)、[Google H5ゲーム向けAd Placement API](https://developers.google.com/ad-placement)、[Ad Placement APIの利用申請](https://developers.google.com/ad-placement/docs/signup?hl=ja)。実効の単価レンジ50〜500円/1,000 Visitsは**意思決定用に置いた仮定**で、これらGoogle公式資料が保証している値ではない。

### 次回広告を出す前にやること（集客から継続へ）

1. **ゲーム内の最小イベント計測**: 流入元（広告UTM、自然SNS共有など）、Puttの最初のショット・ホール完了・ラウンド完了、Sweeperの初回セル開封・クリア・ゲームオーバー、後日の再訪。可能な限り個人情報・認証情報を収集しない。計測の同意・プライバシー記載は導入方法に応じ確認。
2. **SNS共有導線**: Puttの結果画面からXにスコア・チャレンジとリンクを送る（既存案: `hanage-ideas/growth/promotion.md`）。広告由来と共有由来の流入を分ける。
3. **再訪理由の整備**: Puttから週間ランキング・報酬等を小規模検証（既存案: `hanage-ideas/growth/weekly-ranking-rewards.md`）。賞品の配布手段、なりすまし・不正、適用法・規約が未解決なので実施前に確認。報酬の前に無償の週間チャレンジ・称号で検証してもよい。
4. **AdSense再申請対応**: `docs/ADSENSE_CONTENT_PLAN.md`と`PROJECT_STATUS.md`に従い独自コンテンツ・説明文を充実させ、公開と検索エンジン認識を確認する。AdSense未承認のまま収益化前提の広告再投資をしない。
5. **自然流入の基準値**: 広告を出していない期間の月間・日次Visits、Host別Visits、参照元、再訪を確認。ゲーム画面はSPAのためCloudflare PVだけからプレイ回数を推定しない。
6. **次の広告テスト**: 原則少額。4広告グループのうちJP配信はクリック単価の有望候補だが、配信地域等の差を考慮。まずは改善施策の後に、流入から実プレイ・再訪まで同じ時間窓・定義で比較して継続判断する。

評価の優先順位は、**利益を生む継続的な流入を作ること** ＞ 広告指標の見栄え ＞ 計測システム完成。実装は学びを得るために必要な最小限にとどめる。
