# 集客・収益化メモ

最終更新: 2026-09-29

## 目的

Xでの集客テスト、実際の利用状況、ゲーム内広告の収益化判断を、実測と推定を分けて残す。

- 実測値は、X Ads Manager、Cloudflare Web Analytics、各ゲームのランキングD1から取得する。
- 推定値は計画判断のための概算であり、実績値として扱わない。
- 広告の表示位置・同意・プライバシーに関する確定ルールは `docs/ADVERTISING_POLICY.md` を正とする。

### 複数コースへの継続

広告開始後に記録が更新されたプレイヤー20人について、記録のあるコース数を集計した。

| 完走・記録したコース数 | 人数 | 割合 |
| --- | ---: | ---: |
| 1 | 12 | 60% |
| 2 | 6 | 30% |
| 3 | 1 | 5% |
| 4 | 1 | 5% |

- 2コース以上: 8人 / 20人 = 40%
- 3コース以上: 2人 / 20人 = 10%

これは「ランキング登録まで到達した人」を母集団にした深さの指標であり、全訪問者の継続率ではない。

## 現時点のゲーム内広告収益の見立て

まだゲーム内広告は実装していない。AdSenseは2026-09-19に「有用性の低いコンテンツ」で却下されており、Google H5 Games Adsを使う前提条件も満たしていない。

現在のアクセス規模をそのまま将来にも維持できると仮定した場合でも、ゲーム内広告収益はまず月数百〜数千円程度から始まる可能性が高い、という作業仮説を置く。これは実績ではなく、一般的なゲーム広告eCPMと現在の訪問規模から置いた粗いレンジ。

重要な点:

- 現在のX広告費4,000円をゲーム内広告ですぐ回収する前提にはしない。
- 有料流入が止まればアクセスも落ちる可能性があり、収益試算もそのまま維持されない。
- 収益化の意味が大きくなるのは、検索、SNS拡散、再訪などの無料流入が増えてから。
- 広告を入れる場合も、プレイ中ではなく自然な区切りだけにする。確定ルールは `ADVERTISING_POLICY.md` に記録する。

## 現在の判断

1. X広告の1回目は条件を途中で変えず完走させる。
2. 広告期間中にPutt / SweeperのUIを大きく変えない。
3. Puttはランキングデータ上、一部ユーザーが複数コースまで進んでいるため、現時点でゲーム内容を大きく変える根拠はない。
4. 次の優先はゲーム内イベント計測。最低限、以下を候補とする。
   - Putt: first shot / hole complete / round complete
   - Sweeper: first cell open / clear / game over
5. ゲーム内広告の実装は急がない。AdSense再承認、無料流入、実測のプレイ深度を見て再判断する。
6. 次の広告テストではX Ads Managerの消化額、インプレッション、リンククリック、CTR、CPCと、ゲーム内イベントを同じ期間で揃えて比較する。
