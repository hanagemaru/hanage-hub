# hanage.app 文章の方針

サイト内の紹介文、制作ノート、遊び方、更新情報を追加・修正するときの基準。

## 基本方針

- 読んだ人が、ゲームを知らなくても何をするものか理解できる文章にする。
- 簡潔で自然な説明を優先する。多少そっけなくても構わない。
- 文体を演出するための体言止め、短文の連続、余韻を残す言い回しは使わない。
- 「丁寧語をあえて抜く」「文章を不自然に区切る」といった加工をしない。説明文では普通の「です・ます」調を使ってよい。
- 専門用語や他のゲームを知っている前提の比較は、必要な場合にだけ使い、使うなら意味が分かるように書く。
- 説明のためだけに不要な特徴を付け加えない。まず遊び方や仕組みそのものを具体的に説明する。
- 文字数を減らすことを目的にしない。つながる内容は自然な一文にまとめる。
- 制作ノートでは個人の経験や判断を率直に書いてよいが、気取った表現や根拠のない感想を足さない。
- 事実、仕様、日付、操作名は変えない。分からない点は推測で補わず、実装を確認する。

## 例

避ける：

> 指を振る速さが、そのまま球の強さになる。強さを決めるゲージはない。傾斜を読んで狙いを決めたら、あとは最後のひと振り次第。

採用する：

> 画面上で指をスワイプしてパターを振ります。指を動かす速さによって、ボールの強さが変わります。

## ページ別の注意

- ゲーム紹介：何をするゲームで、どう操作するかを先に伝える。
- 作者による説明：紹介文の繰り返しではなく、設計上の意図や工夫を具体的に書く。
- 遊び方：初めて使う人が手順を追える言葉を使う。
- 制作ノート：制作の経緯を自然な段落で説明する。箇条書きはルールの列挙など必要な場合だけ使う。
- 更新情報：変更した内容を事実ベースで説明する。
- プライバシーポリシー・利用規約：法的な正確性を優先し、表現だけを目的に変更しない。

日本語の意味を確定してから、英語版にも自然な表現で反映する。逐語訳はしない。
