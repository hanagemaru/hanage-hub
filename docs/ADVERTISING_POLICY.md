# 広告・同意管理方針

最終更新: 2026-09-05

## 目的と適用範囲

この文書は、`hanage.app` と、そこから案内する hanagemaru 運営のゲームに共通する広告方針の正本です。各ゲームのサブドメイン、正式公開前の `workers.dev` / GitHub Pages などの暫定URLも含みます。別の運営者が提供する外部サイトには適用しません。

この文書は実装・運用上の方針です。利用者向けの説明は `https://hanage.app/privacy/` を正とします。

## 文書の役割分担

| 文書 | 保持する内容 |
| --- | --- |
| この文書 | 全作品に共通する広告、同意、プライバシー保護、公開前確認 |
| 各ゲームの仕様書 | そのゲーム固有の表示タイミング、頻度、画面遷移、失敗時の挙動 |
| 各リポジトリのステータス文書 | 現在の実装・公開状況と次の作業 |
| ハブのプライバシーポリシー | 利用者へ公開する、実際の情報取扱い |

同じルールを複数箇所へ詳細に複製せず、共通事項はこの文書へ、作品固有事項は各仕様書へ記録します。

## 現在の状態

- 現在、ハブおよび掲載作品では広告を配信していません。
- 外部アクセス解析サービスも導入していません。
- 将来の候補は Google AdSense と H5 Games Ads です。採用サービスは導入前に再確認し、公開プライバシーポリシーへ反映します。

## 共通の表示原則

- 広告は、結果表示や複数ステージの区切りなど、操作が止まる自然な区切りにだけ表示します。
- プレイ中、時間計測中、盤面操作中、ショット中には表示しません。
- ゲーム開始、再試行、メニュー移動を不必要に妨げません。
- 同じ画面遷移で二重表示しません。
- 広告を閉じた直後に続けて別の広告を表示しません。
- 広告をコンテンツや操作ボタンに見せかけず、誤タップを誘う配置にしません。
- 広告の取得・表示・同意管理に失敗しても、ゲームの開始、続行、結果確認、再試行を妨げない設計にします。
- 年齢や地域に応じて追加対応が必要な場合は、配信開始前に対象地域と設定を確認します。

## 作品ごとの方針

| 対象 | 現在の方針 |
| --- | --- |
| hanage.app ハブ | 現在は広告なし。将来ページ内広告を置く場合も、閲覧やナビゲーションを覆わない |
| Multicolor Sweeper | 広告は未設計・未実装。盤面プレイ中には表示しない。導入前に固有の表示タイミングと頻度を `SPEC.md` へ確定する |
| Putt | 3ホール終了時、およびラウンド途中から別のニューゲームを始める直前。広告直後や未プレイのラウンド切替では重ねて表示しない |

作品固有の確定仕様は、それぞれのリポジトリにある仕様書を優先します。

## プライバシーと同意

広告導入前に、少なくとも次を完了します。

1. 実際に利用する広告事業者、Cookie等の利用、取得・共有される情報を公開プライバシーポリシーへ記載する。
2. 各ゲームから `https://hanage.app/privacy/` を常時確認できる導線を設ける。
3. Googleの要件に従い、EEA・英国・スイスで広告を配信する場合は、Google認定の同意管理プラットフォーム（CMP）を使用する。
4. 同意が必要な地域では、必要な同意を得るまで対象の広告処理を開始しない。
5. 同意の選択を後から変更できる導線を用意する。
6. 広告事業者へ渡す情報を必要最小限にし、ゲームのランキング認証情報や秘密情報を広告コードへ渡さない。

## ads.txt

AdSenseの承認とサイト情報の確定後、Googleが示す発行者IDを使って `https://hanage.app/ads.txt` を公開します。発行者IDを推測して先に作成しません。内容を変更した場合は、公開URLから取得できることを確認します。

## 導入前チェック

- AdSenseの審査と、使用する広告機能の利用可否が確認できている
- 各ゲームの仕様書に表示タイミング、頻度、二重表示防止、失敗時の挙動がある
- ハブと各ゲームからプライバシーポリシーを開ける
- 公開プライバシーポリシーが実際の広告事業者とデータ取扱いに一致している
- 必要地域のCMPと同意変更導線が動作する
- `ads.txt` が公開URLから取得できる
- 広告ブロック、通信失敗、同意拒否でもゲームを利用できる
- iPhone、iPad、Android、PCで誤タップや画面崩れがない
- テスト広告で確認し、本番広告の自己クリックを行わない

## 変更時の運用

広告事業者、表示箇所、取得情報、同意方法を変更するときは、実装と同じPRでこの文書、対象ゲームの仕様書、公開プライバシーポリシー、ステータス文書の必要箇所を同期します。
