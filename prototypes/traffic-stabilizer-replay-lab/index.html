TRAFFIC STABILIZER · REPLAY LAB

「もう1回」の理由を4方向で比較する実験版です。どれも交通物理の核は同じで、リプレイ動機だけを変えています。
A · MASTERY / SCORE
FLOW SCORE

速さと低JAMを両立すると倍率が伸びる。遅く安全に走るだけでは高得点にならない。

→ 自己ベスト更新でもう1回やりたくなるか？
B · CHOICE / VARIETY
FLOW DRAFT

2周ごとに次の負荷を2択。難しい選択ほどスコア倍率が上がり、毎回コースが育つ。

→ 自分で危険を選ぶことで毎回違う展開になるか？
C · GOAL VARIETY
CONTRACT RUN

同じコースを「低JAM」「タイム」「AUTO BRAKE禁止」に目標だけ変えて攻略。

→ 同じ物理でも目標が違えば繰り返せるか？
D · LONG GOALS
MILESTONES

Campaign / Daily / Endlessを横断する12個の長期目標。プレイヤー能力は強化しない。

→ 未達成目標が戻ってくる理由になるか？
見るポイント：①終わった直後にもう1回押したくなるか ②車間調整の面白さが強くなったか ③作業感・報酬のためだけのプレイになっていないか。広告は各runの終了点だけを候補とし、この比較版には入れていません。
