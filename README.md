# hanage-hub

`hanage.app` で公開する、個人制作ゲーム・Webアプリのハブサイトです。

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run lint
npm run build
```

## Planned domain structure

- Hub: `https://hanage.app/`
- Gradient Sweeper: `https://sweeper.hanage.app/`

The site is built with Next.js and TypeScript and is intended for deployment on Netlify.
